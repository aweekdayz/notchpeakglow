## Applying the reading to PeakGlow

The complete reading reinforces six priorities: native macOS command access; pointer and keyboard interaction that remain available until people finish; truthful sensor/pause status; precise numerical settings with contextual explanations; readable adaptive layouts and assistive access; restrained system material and motion. Platform-specific technologies were read but are not a reason to add unrelated features to this utility. See [HIG-Review.md](HIG-Review.md) for the source observations and implementation proposals.
